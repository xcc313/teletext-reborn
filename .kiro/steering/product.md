# Product Steering

## Vision

Teletext Reborn — "Looks like 1985. Thinks like 2026." Resurrect broadcast teletext as a live, AI-powered information terminal. Kiroween 2026 entry, Resurrection category.

## Target Users

- Nostalgic viewers who remember teletext and want to feel it again
- Anyone who wants a glanceable, ultra-light live info dashboard (kiosk / low-bandwidth scenarios)
- Hackathon judges testing the demo with zero configuration

## MVP Pages

- 100 — index / service overview
- 101 — live news headlines (demo feed fallback, no key required)
- 302 — live weather (Open-Meteo, keyless)
- 888 — about / subtitles-style info page

## Non-Goals (MVP)

- Canvas renderer upgrade, animations beyond authentic teletext feel
- User accounts, personalization, server-side persistence
- Transit / sports pages (post-MVP)
- Mobile apps — desktop browser is the judging target

## Product Rules

- The app must be fully functional with zero API keys configured
- Authenticity beats modern UI conventions: never add rounded corners, gradients, or modern chrome
- Every page must pass the validation gate before display
